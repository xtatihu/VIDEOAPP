# नूर — APK डाउनलोड पेज

नूर एक निजी एंड्रॉइड जर्नल की डायरेक्ट-APK लैंडिंग है। पेज हिन्दी में है: वर्जन, साइज़, SHA-256, इंस्टॉल के स्टेप, और डाउनलोड डायलॉग।

साथ में जो फ़ाइल है (`public/downloads/noor-2.3.1.apk`) वह एक **सैंपल पैकेज** है, ताकि बटन काम करे। यह इंस्टॉल होने वाला एंड्रॉइड ऐप नहीं है।

## चलाना

```bash
npm install
npm run dev
```

डेव सर्वर [http://localhost:3000](http://localhost:3000) पर खुलता है।

## अपना APK लगाना

1. साइन किया हुआ APK यहाँ रखो: `public/downloads/noor-2.3.1.apk`
2. नाम, वर्जन, तारीख और कॉपी `src/lib/content.ts` में बदलो। फ़ाइल का नाम वहीं `filename` से जुड़ा है।
3. पेज रिफ्रेश करो। साइज़ और SHA-256 फ़ाइल से खुद बनते हैं।

बड़ा APK भी पूरा मेमोरी में नहीं पढ़ा जाता — हैश स्ट्रीम से बनता है।
